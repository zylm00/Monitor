# Monitor
监控屏幕闪烁发消息到手机，接收多个qq或微信登陆在电脑上
# 任务栏消息监控（Taskbar Icon Monitor）

一个基于像素亮度差异检测的 Windows 桌面小工具：持续监控任务栏（或屏幕任意区域）上指定图标是否发生"闪烁"（例如聊天软件收到新消息时图标会闪动），一旦检测到变化就通过 Webhook 推送提醒到手机。

## 功能特点

- **多图标并发监控**：一次可以记录多个图标坐标，同时监控。
- **可视化坐标记录**：点击"记录坐标"后弹出跟随鼠标的悬浮倒计时窗口 + 提示音，倒计时结束自动读取鼠标位置，不用再靠猜测像素坐标。
- **自适应基准亮度**：启动监控前自动采样多次计算每个图标的基准亮度，减少环境光/主题差异带来的误报。
- **冷却机制**：检测到闪烁后进入冷却期，避免同一次消息重复推送。
- **多线程 GUI**：截图检测跑在后台线程，不阻塞 Tkinter 主界面。
- **可扩展推送渠道**：默认接入 [ntfy.sh](https://ntfy.sh/)，`send()` 函数改几行就能换成企业微信机器人、飞书自定义机器人、PushPlus、Server酱等其他 Webhook 推送方式。

## 技术栈

- `tkinter` / `ttk` — 桌面 GUI
- `mss` — 高性能屏幕截图
- `numpy` + `Pillow` — 图像转数组与亮度计算
- `pyautogui` — 获取鼠标坐标
- `requests` — 调用推送 Webhook
- `threading` — 后台监控循环与异步推送

## 安装

```bash
pip install -r requirements.txt
```

## 使用方法

1. 运行脚本：

   ```bash
   python monitor.py
   ```

2. 在"推送地址"里填入你自己的 [ntfy](https://ntfy.sh/) 频道地址（或替换成你自己接入的其他 Webhook 服务）。
3. 点击"记录坐标"，把鼠标移到要监控的图标上，等悬浮窗倒计时结束即可记录成功。可以点"+ 添加图标"监控多个位置。
4. 点击"开始监控"，程序会先采集基准亮度，之后持续检测每个图标区域的亮度变化，一旦超过阈值就推送提醒。

## 配置项

脚本顶部可以调整以下参数：

| 变量 | 说明 |
| --- | --- |
| `NTFY_URL` | 默认推送地址 |
| `SIZE` | 每个图标的采样区域半径（像素） |
| `INTERVAL` | 监控循环间隔（秒） |
| `COOLDOWN` | 同一图标推送冷却时间（秒） |
| `BLINK_THRESHOLD` | 判定为"闪烁"的亮度差阈值 |
| `BASELINE_SAMPLES` | 启动时采集基准亮度的次数 |

## 注意事项

- 仅在 Windows 上测试通过（`winsound` 提示音为 Windows API，其他平台会自动降级为系统提示音）。
- 请勿在公开仓库中提交自己的私人推送地址/Token，会导致任何人都能给你发消息。
